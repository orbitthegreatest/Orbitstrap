Before you ask

The two questions every bootstrapper gets, answered straight.

Can it get me banned?
No. Orbitstrap doesn't inject cheats or bypass Roblox's security — it's a launcher and configuration manager, not an exploit tool. It changes how Roblox is launched and how the client looks, not how the game runs.
Is it a virus?
No. Orbitstrap is fully open source — every line is right there on GitHub for you to read. If your antivirus flags it, that's a false positive triggered by how bootstrappers interact with the Roblox process, not by anything malicious in the code.
